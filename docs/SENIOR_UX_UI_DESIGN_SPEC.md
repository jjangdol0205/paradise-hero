## 1. 개요 및 인지 공학적 배경 (Cognitive Ergonomics)

`paradise-hero.com`의 주 이용자는 **50대~70대 시니어 여성(88%)**이며, **모바일 접속률이 94%**에 달합니다. 

노화에 따른 시각·인지·운동 능력의 자연스러운 변화(노안, 수정체 황변에 따른 청색광 투과율 저하, 미세 손떨림, 디지털 조작에 대한 불안감)를 깊이 이해하지 못한 일반적인 웹 UI는 시니어 고객에게 심각한 스트레스와 이탈을 초래합니다. 

본 설계서는 돋보기안경 없이도 편안하게 읽히고, 오동작에 대한 두려움 없이 직관적으로 탐색할 수 있는 **"대한민국 최고 수준의 효도형 안심 UX/UI 표준"**을 정의합니다.

## 2. 색상 체계 및 초고대비(WCAG AAA) 명도비 규격

### 2.1 팔레트 구성 및 명도 대비 검증 (Contrast Ratio)
WCAG 2.1 AAA 기준은 일반 텍스트의 경우 배경 대비 최소 **7.0:1 이상**, 큰 텍스트(18pt 이상)는 **4.5:1 이상**의 명도 대비를 요구합니다. 본 플랫폼은 모든 영역에서 이를 초과 달성합니다:

```
┌────────────────────────────────────────────────────────────────────────┐
│             paradise-hero.com Senior Color Contrast Matrix             │
├───────────────────┬──────────┬──────────┬──────────────┬───────────────┤
│ 역할 (Role)       │ 색상명   │ Hex Code │ 배경색 대비비│ AAA 적합 여부 │
├───────────────────┼──────────┼──────────┼──────────────┼───────────────┤
│ Main Text         │ 다크차콜 │ `#1F2937`│ 12.8 : 1     │ ✅ 초과 통과 │
│                   │          │ (on `#FAFAF8`)          │ (기준: 7.0:1) │
├───────────────────┼──────────┼──────────┼──────────────┼───────────────┤
│ Primary Button    │ 에메랄드 │ `#1B4D3E`│ 8.6 : 1      │ ✅ 초과 통과 │
│ Text              │ 화이트   │ `#FFFFFF`│ (on `#1B4D3E`)          │ (기준: 7.0:1) │
├───────────────────┼──────────┼──────────┼──────────────┼───────────────┤
│ Accent Gold       │ 골드     │ `#D4AF37`│ 4.8 : 1      │ ✅ 큰글씨 통과│
│ (VIP/뱃지)        │ 딥에메랄 │ `#0E2820`│ (on `#0E2820`)          │ (기준: 4.5:1) │
├───────────────────┼──────────┼──────────┼──────────────┼───────────────┤
│ Background Canvas │ 소프트   │ `#FAFAF8`│ 눈부심 방지  │ 피로도 감소   │
│                   │ 아이보리 │          │ 무광 매트    │               │
└───────────────────┴──────────┴──────────┴──────────────┴───────────────┘
```

#### 시각 보호를 위한 2대 원칙
1. **순백색(`#FFFFFF`) 배경 지양**: 고휘도 OLED 스마트폰에서 순백색 배경은 시니어 망막에 심한 눈부심과 눈 시림을 유발합니다. 따뜻하고 편안한 미색인 **소프트 아이보리(`#FAFAF8`)**를 캔버스 기본색으로 채택합니다.
2. **청색/보라색 텍스트 지양**: 노화된 수정체는 단파장(푸른빛)을 흡수하여 흐릿하게 보입니다. 신뢰와 평온을 주는 에메랄드 그린(`#1B4D3E`)과 고대비 차콜(`#1F2937`)을 주색으로 사용합니다.

## 3. 타이포그래피 및 [글자크게 가+] 3단계 동적 확장 시스템

### 3.1 기본 폰트 규격
- **서체 (Font Family)**: `Pretendard`, `NanumSquareRound`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif` (모바일 가독성이 뛰어난 굴림 없는 볼드 고딕 계열).
- **기본 본문 크기**: **`18px`** (일반 웹사이트의 14~15px 대비 25% 이상 확대 적용).
- **행간 (Line Height)**: **`1.8`** (글자 줄 간격을 넉넉히 주어 줄바꿈 시 시선 이탈 방지).
- **자간 (Letter Spacing)**: **`0.02em`** (글자가 뭉쳐 보이지 않도록 미세 여백 확보).

### 3.2 [글자크게 가+] 3단계 토글 위젯 기술 사양
시니어가 돋보기를 찾지 않고도 손가락 터치 한 번으로 웹사이트 전체 글씨 크기를 조절할 수 있는 반응형 접근성 위젯을 화면 우측 상단/플로팅으로 제공합니다:

```
[3단계 텍스트 확장 모드 사양표]
┌───────────────┬────────────┬────────────┬────────────┐
│ 레벨          │ 본문 크기  │ 소제목     │ 대제목     │
├───────────────┼────────────┼────────────┼────────────┤
│ 1단계 (기본)  │ 18px (1.0x)│ 22px       │ 28px       │
│ 2단계 (크게)  │ 21px (1.16x│ 26px       │ 32px       │
│ 3단계 (아주크게│ 24px (1.33x│ 30px       │ 36px       │
└───────────────┴────────────┴────────────┴────────────┘
```

#### CSS 변수 기반 구현 아키텍처
```css
:root {
  --font-base: 18px;
  --font-subheading: 22px;
  --font-heading: 28px;
  --line-height-body: 1.8;
}

body.font-lg {
  --font-base: 21px;
  --font-subheading: 26px;
  --font-heading: 32px;
}

body.font-xl {
  --font-base: 24px;
  --font-subheading: 30px;
  --font-heading: 36px;
}
```
- **영속성 (Persistence)**: 사용자가 선택한 폰트 크기 설정은 브라우저 `localStorage`에 자동 저장되어, 다음 방문 시에도 동일한 크기로 자동 유지됩니다.

## 4. 터치 타깃 및 손가락 운동 인체공학 (Touch Targets Ergonomics)

```
[시니어 안심 터치 타깃 규격도]
┌────────────────────────────────────────────────────────┐
│  여백 16px                                             │
│  ┌──────────────────────────────────────────────────┐  │
│  │                                                  │  │
│  │   [ 💚 1-Click 노래 듣기 (멜론/지니) ]            │  │ 높이 56px~64px
│  │                                                  │  │ (터치 안전 영역)
│  └──────────────────────────────────────────────────┘  │
│  여백 16px                                             │
│  ┌──────────────────────────────────────────────────┐  │
│  │   [ 🌟 영웅님께 황금 응원 보내기 ]                │  │ 높이 56px~64px
│  └──────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

1. **최소 터치 크기 (Minimum Touch Target)**:
   - 모든 주요 버튼, 링크, 입력창의 터치 영역 높이를 **최소 `56px` (권장 `64px`)**로 설정합니다 (W3C 권장 최소치 44px 대비 27% 이상 대형화).
2. **버튼 간 안전 여백 (Safe Separation Margin)**:
   - 인접한 버튼 사이의 마진을 **최소 `16px 이상`** 유지하여, 손가락이 두껍거나 손떨림이 있는 시니어 고객이 원치 않는 버튼을 잘못 누르는 오류(Fat-Finger Error)를 원천 차단합니다.
3. **즉각적인 시각 피드백 (Tactile Visual Feedback)**:
   - 버튼을 터치하는 순간 부드러운 스케일 축소(`transform: scale(0.97)`)와 은은한 황금빛 테두리 글로우 효과(`box-shadow: 0 0 12px rgba(212, 175, 55, 0.5)`)를 주어 "내가 버튼을 눌렀다"는 사실을 0.1초 만에 인지하도록 지원합니다.

## 5. 무장애 탐색 및 100% 한글 용어화 (Frictionless Navigation)

### 5.1 숨김 메뉴(햄버거 버튼) 배제 원칙
- 젊은 층이 주로 쓰는 3단 가로줄(햄버거 아이콘 `☰`)은 시니어들에게 "메뉴가 어디 숨어있는지 모르는" 치명적인 사용성 장벽입니다.
- 상단 또는 하단에 **명확한 한글 라벨과 아이콘이 결합된 4~5개 핵심 탭**을 항상 밖으로 노출합니다:
  - 🏠 **처음으로** (`index.html`)
  - 📻 **김쌤 라디오** (`radio.html`)
  - 🎵 **노래 듣기 가이드** (`stream.html`)
  - 💬 **파라다이스 사랑방** (`community.html`)
  - 👑 **황금빛 VIP** (`vip.html`)

## 6. 하단 고정 라디오 오디오 플레이어 사양 (Persistent Sticky Audio Player)

```
[하단 고정 오디오 플레이어 UI 레이아웃]
┌────────────────────────────────────────────────────────────────────────┐
│ [▶ 재생/일시정지: 60px] "김쌤의 영웅 라디오 1화 연속 듣기" [음량 🔊] │
└────────────────────────────────────────────────────────────────────────┘
```

- **상시 고정 (Sticky Bottom)**: 페이지를 스크롤하거나 다른 사랑방 글을 읽어도 화면 최하단에 항상 부드럽게 고정됩니다.
- **조작 단순화**:
  - 복잡한 이퀄라이저나 셔플 버튼을 없애고, **큼직한 재생/일시정지 버튼 (직경 60px)**과 **음량 조절 슬라이더**, **음소거 버튼** 단 3가지만 배치합니다.
- **스트리밍 데이터 절약 안내**:
  - 와이파이(Wi-Fi) 미연결 시 데이터 통화료 안내 문구를 친절하게 툴팁으로 제공합니다.

## 7. 검증 및 품질 감사 프로토콜 (Verification & Lighthouse Audit)

본 설계서는 프론트엔드 빌드 및 CI/CD 파이프라인에서 다음 기준을 충족해야만 최종 합격(PASS) 판정을 받습니다:

1. **Google Lighthouse 접근성 점수**: **96점 이상 / 100점 만점**
2. **axe-core 접근성 린트 위반**: **0건 (Zero Violations)**
3. **명도 대비 검사**: 전 페이지 텍스트 명도비 `8.5:1 이상` (WCAG AAA 통과)
4. **버튼 크기 검증**: 클릭 가능한 모든 요소의 바운딩 박스가 `56px × 56px 이상` 준수
